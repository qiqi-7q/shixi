# 车辆插件接口文档

---

## 一、车辆管理接口

### 1.1 获取车辆列表（高级搜索）

**接口路径：** `/plugins/vehicle/search`

**请求方法：** `POST`

**请求参数：**

| 参数名        | 类型         | 位置    | 必填 | 说明                   |
|------------|------------|-------|----|----------------------|
| skip       | int        | Query | 否  | 跳过记录数，默认 0           |
| limit      | int        | Query | 否  | 返回记录数，默认 100，最大 1000 |
| conditions | List[dict] | Body  | 是  | 搜索条件列表               |

**请求体示例：**

```json
{
  "conditions": [
    {
      "advanced_field": "parking_location",
      "advanced_operator": "contains",
      "advanced_value": "A区"
    },
    {
      "advanced_field": "owner_name",
      "advanced_operator": "icontains",
      "advanced_value": "zhang"
    }
  ]
}
```

**响应参数：**

| 参数名            | 类型     | 说明     |
|----------------|--------|--------|
| id             | int    | 车辆ID   |
| model          | string | 车型     |
| vehicle_code   | string | 车辆编号   |
| vin_code       | string | VIN码   |
| owner_name     | string | 车主权限   |
| plate_number   | string | 车牌号    |
| vehicle_status | string | 车辆状态   |
| test_status    | string | 测试状态   |
| ...            | ...    | 其他车辆字段 |

**响应示例：**

```json
[
  {
    "id": 1,
    "model": "Tesla Model 3",
    "vehicle_code": "VC001",
    "vin_code": "LV1234567890ABCDE",
    "owner_name": "张三",
    "plate_number": "京A12345",
    "vehicle_status": "available",
    "test_status": "支持全部测试",
    "created_at": "2024-01-01T00:00:00",
    "updated_at": "2024-01-01T00:00:00"
  }
]
```

### 1.2 获取车辆列表（固定字段查询）

**接口路径：** `/plugins/vehicle/`

**请求方法：** `GET`

**请求参数：**

| 参数名            | 类型     | 位置    | 必填 | 说明                   |
|----------------|--------|-------|----|----------------------|
| skip           | int    | Query | 否  | 跳过记录数，默认 0           |
| limit          | int    | Query | 否  | 返回记录数，默认 100，最大 1000 |
| vehicle_status | string | Query | 否  | 车辆状态                 |
| vin_code       | string | Query | 否  | VIN码（模糊搜索）           |
| group          | string | Query | 否  | 车辆组别                 |
| model          | string | Query | 否  | 车型                   |

**请求示例：**

```
GET /plugins/vehicle/?vehicle_status=available&model=Tesla
```

**响应参数：** 同 1.1

---

### 1.3 获取车辆统计

**接口路径：** `/plugins/vehicle/stats`

**请求方法：** `GET`

**请求参数：** 无

**响应参数：**

| 参数名         | 类型  | 说明     |
|-------------|-----|--------|
| total       | int | 车辆总数   |
| available   | int | 可用车辆数  |
| borrowed    | int | 已借出车辆数 |
| maintenance | int | 维护中车辆数 |

**响应示例：**

```json
{
  "total": 100,
  "available": 80,
  "borrowed": 15,
  "maintenance": 5
}
```

---

### 1.4 获取单个车辆

**接口路径：** `/plugins/vehicle/{vehicle_id}`

**请求方法：** `GET`

**路径参数：**

| 参数名        | 类型  | 必填 | 说明   |
|------------|-----|----|------|
| vehicle_id | int | 是  | 车辆ID |

**响应参数：** 同 1.1

---

### 1.5 创建车辆

**接口路径：** `/plugins/vehicle/`

**请求方法：** `POST`

**请求参数：**

| 参数名                    | 类型     | 位置   | 必填 | 说明         |
|------------------------|--------|------|----|------------|
| model                  | string | Body | 是  | 车型         |
| vehicle_code           | string | Body | 是  | 车辆编号       |
| vin_code               | string | Body | 是  | VIN码       |
| owner_name             | string | Body | 是  | 车主权限       |
| plate_number           | string | Body | 是  | 车牌号        |
| editor                 | string | Body | 是  | 最后编辑人      |
| vehicle_stage          | string | Body | 否  | 车辆阶段       |
| configuration          | string | Body | 否  | 车辆配置       |
| parking_location       | string | Body | 否  | 停车地点       |
| engine_num             | string | Body | 否  | 驱动电机号/发动机号 |
| temp_plate_expire_date | date   | Body | 否  | 临牌到期时间     |
| temp_plate_count       | int    | Body | 否  | 临牌已办理次数    |
| remarks                | string | Body | 否  | 备注         |

**请求示例：**

```json
{
  "model": "Tesla Model 3",
  "vehicle_code": "VC001",
  "vin_code": "LV1234567890ABCDE",
  "owner_name": "张三",
  "plate_number": "京A12345",
  "editor": "李四",
  "parking_location": "A区001"
}
```

**响应参数：** 同 1.1

---

### 1.6 更新车辆

**接口路径：** `/plugins/vehicle/{vehicle_id}`

**请求方法：** `PUT`

**路径参数：**

| 参数名        | 类型  | 必填 | 说明   |
|------------|-----|----|------|
| vehicle_id | int | 是  | 车辆ID |

**请求参数：** 同 1.5，所有字段可选

**响应参数：** 同 1.1

---

### 1.7 删除车辆

**接口路径：** `/plugins/vehicle/{vehicle_id}`

**请求方法：** `DELETE`

**路径参数：**

| 参数名        | 类型  | 必填 | 说明   |
|------------|-----|----|------|
| vehicle_id | int | 是  | 车辆ID |

**响应参数：**

| 参数名     | 类型     | 说明     |
|---------|--------|--------|
| message | string | 操作结果信息 |

**响应示例：**

```json
{
  "message": "Vehicle deleted successfully"
}
```
