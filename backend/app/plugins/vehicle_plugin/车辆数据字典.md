## 一、枚举类型定义

### 1.1 VehicleStatus 车辆状态

| 枚举值 | 英文标识 | 中文说明 |
|--------|---------|----------|
| available | AVAILABLE | 可用 |
| borrowed | BORROWED | 已借出 |
| maintenance | MAINTENANCE | 维护中 |

### 1.2 VehicleGroup 车辆组别

| 枚举值 | 英文标识 | 中文说明 |
|--------|---------|----------|
| driving_group | DRIVEING | 行车组 |
| parking_group | PARKING | 泊车组 |
| warning_group | WARNNING | 预警组 |

### 1.3 TestStatus 测试状态

| 枚举值 | 英文标识 | 中文说明 |
|--------|---------|----------|
| 支持全部测试 | ALL_SUPPORT | 支持全部测试 |
| 不支持泊车测试 | NO_PARKING | 不支持泊车测试 |
| 不支持行车测试 | NO_DRIVING | 不支持行车测试 |
| 不支持后向预警测试 | NO_BACKWARNING | 不支持后向预警测试 |
| 不支持全部测试 | NO_SUPPORT | 不支持全部测试 |
| 生产中 | PRODUCING | 车辆生产中 |
| 外借中 | BORROWING | 车辆外借中 |

### 1.4 BorrowStatus 借用状态

| 值 | 中文说明 |
|----|----------|
| active | 借用中 |
| returned | 已归还 |
| cancelled | 已取消 |

> **注意：** BorrowStatus 未定义为枚举类型，以字符串形式存储，取值范围为上述三个值。

## 四、表关联关系

```
vehicles (1) ──────< borrow_records (N)
    │                      │
    │  vehicles.id         │  borrow_records.vehicle_id
    │                      │
    └── 一对多关系 ─────────┘
```

| 关系 | 说明 |
|------|------|
| vehicles → borrow_records | 一对多：一辆车辆可对应多条借用记录 |
| borrow_records → vehicles | 多对一：每条借用记录关联一辆车辆 |

**关联字段：** `borrow_records.vehicle_id` → `vehicles.id`

**ORM关系：**
- `Vehicle.borrow_records`：通过 `relationship` 获取该车辆的所有借用记录
- `BorrowRecord.vehicle`：通过 `relationship` 获取该借用记录关联的车辆

## 七、业务规则说明

### 7.1 车辆创建校验规则

| 校验项 | 错误信息 | 说明 |
|--------|---------|------|
| vehicle_code 非空 | Vehicle code is missing | 车辆编号必填 |
| vin_code 非空 | VIN code is missing | VIN码必填 |
| model 非空 | Model is missing | 车型必填 |
| owner_name 非空 | Owner name is missing | 车主权限必填 |
| plate_number 非空 | Plate number is missing | 车牌号必填 |
| editor 非空 | Editor is missing | 最后编辑人必填 |
| vehicle_code 唯一 | vehicle_code already exists | 车辆编号不能重复 |
| vin_code 唯一 | vin_code already exists | VIN码不能重复 |

### 7.2 借用记录创建校验规则

| 校验项 | 错误信息 | 说明 |
|--------|---------|------|
| borrower 非空 | Borrower is missing | 借用人必填 |
| borrow_time 非空 | Borrow time is missing | 借用时间必填 |
| 车辆存在性 | Vehicle not found | 关联的车辆必须存在 |

### 7.3 车辆状态联动规则

| 业务操作 | 车辆状态变更 | 说明 |
|---------|-------------|------|
| 创建借用记录 | → borrowed | 车辆被借出，状态变为已借出 |
| 归还车辆 | → available | 归还后车辆恢复为可用 |
| 取消借用 | → available | 取消借用后车辆恢复为可用 |
