# 车辆管理插件接口文档

---

## 一、接口总览

### 1.1 车辆管理接口（前缀：`/api/vehicle`）

| 接口路径 | 方法 | 说明 |
|---------|------|------|
| `/api/vehicle/stats/overview` | GET | 获取车辆概览统计（卡片数据） |
| `/api/vehicle/stats/utilization` | GET | 获取车辆使用率统计（按车辆统计） |
| `/api/vehicle/stats/status_distribution` | GET | 获取车辆状态分布（饼图） |
| `/api/vehicle/advsearch` | POST | 车辆高级查询 |
| `/api/vehicle/fixsearch` | GET | 车辆固定字段查询 |
| `/api/vehicle/createvehicle` | POST | 创建车辆 |
| `/api/vehicle/getstatus/{vehicle_id}` | GET | 获取车辆状态 |
| `/api/vehicle/getvehicle/{vehicle_id}` | GET | 获取单个车辆信息 |
| `/api/vehicle/updatevehicle/{vehicle_id}` | PUT | 更新车辆信息 |
| `/api/vehicle/delvehicle/{vehicle_id}` | DELETE | 删除车辆 |

### 1.2 借用管理接口（前缀：`/api/borrow`）

| 接口路径 | 方法 | 说明 |
|---------|------|------|
| `/api/borrow/stats/overview` | GET | 获取借用概览统计（卡片数据） |
| `/api/borrow/stats/status_distribution` | GET | 获取借用状态分布（饼图） |
| `/api/borrow/fixsearch` | GET | 借用记录固定字段查询 |
| `/api/borrow/advsearch` | POST | 借用记录高级查询 |
| `/api/borrow/createborrow` | POST | 创建借用记录 |
| `/api/borrow/getborrow/{record_id}` | GET | 获取单个借用记录 |
| `/api/borrow/updateborrow/{record_id}` | PUT | 更新借用记录 |
| `/api/borrow/delborrow/{record_id}` | DELETE | 删除借用记录 |
| `/api/borrow/returnvehicle/{record_id}` | POST | 归还车辆 |
| `/api/borrow/cancelborrow/{record_id}` | POST | 取消借用 |

## 二、统一响应格式

所有接口均采用以下统一响应格式：

```json
{
    "code": 200,
    "message": "success",
    "data": <业务数据或null>
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，200表示成功，400表示失败 |
| message | string | 响应消息 |
| data | object/array/null | 业务数据，失败时为null |

**列表查询接口统一返回格式：**

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "items": [...],   // 数据列表
        "total": 100,     // 总条数
        "skip": 0,        // 跳过条数
        "limit": 10       // 每页条数
    }
}
```

## 三、车辆管理接口详情

### 3.1 获取车辆概览统计

**接口路径：** `/api/vehicle/stats/overview`

**请求方法：** `GET`

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| model | string | Query | 否 | None | 车型（模糊匹配，支持like查询） |
| vin_code | string | Query | 否 | None | VIN码（模糊匹配） |
| group | string | Query | 否 | None | 组别（支持中文值：行车组/泊车组/预警组） |
| vehicle_status | string | Query | 否 | None | 车辆状态（支持中文值：可借用/已借出/维护中） |
| test_status | string | Query | 否 | None | 测试状态（支持中文值或英文枚举名） |
| start_date | string | Query | 否 | None | 统计起始日期（格式：YYYY-MM-DD） |
| end_date | string | Query | 否 | None | 统计截止日期（格式：YYYY-MM-DD） |

**请求示例：**
```
GET /api/vehicle/stats/overview?model=T03&group=行车组&vehicle_status=可借用&test_status=支持全部测试
```

**成功响应：**

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "total": 50,
        "available": 30,
        "borrowed": 15,
        "maintenance": 5
    }
}
```

**响应字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| total | int | 车辆总数 |
| available | int | 可用车辆数 |
| borrowed | int | 已借出车辆数 |
| maintenance | int | 维护中车辆数 |

### 3.2 获取车辆使用率统计

**接口路径：** `/api/vehicle/stats/utilization`

**请求方法：** `GET`

**统计逻辑：**
- 每辆车的借用次数：同一车辆同一天多次借用只算一次
- 占比：该车借用次数 / 所有车总借用次数 * 100%

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| model | string | Query | 否 | None | 车型（模糊匹配） |
| vin_code | string | Query | 否 | None | VIN码（模糊匹配） |
| group | string | Query | 否 | None | 组别（行车组/泊车组/预警组） |
| vehicle_status | string | Query | 否 | None | 车辆状态（可借用/已借出/维护中） |
| test_status | string | Query | 否 | None | 测试状态（中文值或英文枚举名） |
| start_date | string | Query | 否 | None | 开始日期 (YYYY-MM-DD) |
| end_date | string | Query | 否 | None | 结束日期 (YYYY-MM-DD) |

**请求示例：**
```
GET /api/vehicle/stats/utilization?model=T03&group=行车组&start_date=2026-06-01&end_date=2026-06-30
```

**成功响应：**

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "items": [
            {"vehicle_id": 1, "model": "T03", "vehicle_code": "V001", "vin_code": "LSVAU2188N1234567", "borrow_count": 15, "proportion": 33.33},
            {"vehicle_id": 2, "model": "T03", "vehicle_code": "V002", "vin_code": "LSVAU2188N1234568", "borrow_count": 12, "proportion": 26.67},
            {"vehicle_id": 3, "model": "C11", "vehicle_code": "V003", "vin_code": "LSVAU2188N1234569", "borrow_count": 10, "proportion": 22.22},
            {"vehicle_id": 4, "model": "C01", "vehicle_code": "V004", "vin_code": "LSVAU2188N1234570", "borrow_count": 8, "proportion": 17.78}
        ],
        "total_borrow_count": 45,
        "total_vehicle_count": 4
    }
}
```

**响应字段说明：**

| 字段名 | 类型 | 说明 |
|--------|------|------|
| items | array | 车辆列表 |
| items[].vehicle_id | int | 车辆ID |
| items[].model | string | 车型名称 |
| items[].vehicle_code | string | 车辆编号 |
| items[].vin_code | string | VIN码 |
| items[].borrow_count | int | 该车借用次数（去重后） |
| items[].proportion | float | 占比（该车借用次数/总借用次数，保留2位小数） |
| total_borrow_count | int | 所有车总借用次数 |
| total_vehicle_count | int | 符合条件的车辆总数 |

### 3.4 车辆高级查询

**接口路径：** `/api/vehicle/advsearch`

**请求方法：** `POST`

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| skip | int | Query | 否 | 0 | 跳过记录数（≥0） |
| limit | int | Query | 否 | 100 | 返回记录数（1-1000） |
| conditions | List[dict] | Body | 是 | - | 高级查询条件列表 |

**conditions 条件格式：**

```json
[
    {
        "advanced_field": "字段名",
        "advanced_operator": "操作符",
        "advanced_value": "值"
    }
]
```

| 字段 | 说明 |
|------|------|
| advanced_field | 查询字段，必须在 VEHICLE_WHITELIST 中 |
| advanced_operator | 操作符，必须在 ADVANCED_OPERATORS 中 |
| advanced_value | 查询值 |

**支持的操作符（advanced_operator）：**

| 操作符 | 说明 |
|--------|------|
| contains | 包含（模糊匹配） |
| equals | 等于 |
| notEquals | 不等于 |
| startsWith | 开头是 |
| endsWith | 结尾是 |

**可查询字段（advanced_field）：**

id、model、vehicle_code、vin_code、owner_name、plate_number、editor、group、vehicle_status、test_status、vehicle_stage、configuration、parking_location、engine_num、temp_plate_expire_date、temp_plate_count、remarks、created_at、updated_at

**请求示例：**
```
POST /api/vehicle/advsearch?skip=0&limit=10
```
```json
[
    {
        "advanced_field": "vehicle_status",
        "advanced_operator": "equals",
        "advanced_value": "可借用"
    },
    {
        "advanced_field": "model",
        "advanced_operator": "contains",
        "advanced_value": "C11"
    }
]
```

**成功响应：**

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "items": [
            {
                "id": 1,
                "model": "C11",
                "vehicle_code": "V001",
                "vin_code": "LSVAU2188N2123456",
                "owner_name": "张三",
                "plate_number": "京A12345",
                "editor": "管理员",
                "group": "行车组",
                "vehicle_status": "可借用",
                "test_status": "支持全部测试",
                "vehicle_stage": "量产",
                "configuration": "高配",
                "parking_location": "A区1号",
                "engine_num": "ENG001",
                "temp_plate_expire_date": "2025-06-30",
                "temp_plate_count": 1,
                "remarks": null,
                "created_at": "2025-01-15T10:30:00",
                "updated_at": "2025-01-15T10:30:00"
            }
        ],
        "total": 100,
        "skip": 0,
        "limit": 10
    }
}
```

**错误响应：**

| code | message | 说明 |
|------|---------|------|
| 400 | 高级查询信息无效 | conditions 为空 |
| 400 | 无效的字段: xxx | 字段不在白名单中 |
| 400 | 无效的操作: xxx | 操作符不被支持 |

### 3.9 更新车辆信息

**接口路径：** `/api/vehicle/updatevehicle/{vehicle_id}`

**请求方法：** `PUT`

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 说明 |
|--------|------|------|------|------|
| vehicle_id | int | Path | 是 | 车辆ID |

**Body 参数（JSON，所有字段均为可选，仅传入需更新的字段）：**

| 参数名 | 类型 | 说明 |

| vehicle_code | Optional[string(max=50)] | 车辆编号 |
| vin_code | Optional[string(max=17)] | VIN码 |
| owner_name | Optional[string(max=100)] | 车主权限 |
| plate_number | Optional[string(max=20)] | 车牌号 |
| vehicle_stage | Optional[string(max=20)] | 车辆阶段 |
| configuration | Optional[string(max=200)] | 车辆配置 |

| temp_plate_expire_date | Optional[date] | 临牌到期时间 |
| temp_plate_count | Optional[int] | 临牌已办理次数 |
| editor | Optional[string(max=20)] | 最后编辑人 |

```
PUT /api/vehicle/updatevehicle/1
```

```json
{
    "code": 200,
```

| code | message | 说明 |

```
DELETE /api/vehicle/delvehicle/1
```

## 五、业务流程说明

### 5.1 车辆借用-归还流程

```
车辆可用(可借用)
    │
    ▼
创建借用记录 ───────────► 车辆状态变为已借出
    │                         │
    │                         ▼
    │                    归还车辆(returnvehicle) ──► 车辆恢复可用(可借用)
    │                    借用记录变为已归还(returned)
    │
    │
    └──► 取消借用(cancelborrow) ──► 车辆恢复可用(可借用)
                                  借用记录变为已取消(cancelled)
```

### 5.2 状态变更规则

| 当前车辆状态 | 可执行操作 | 变更后状态 |
|-------------|-----------|-----------|
| 可借用 | 创建借用记录 | 已借出 |
| 已借出 | 归还车辆 | 可借用 |
| 已借出 | 取消借用 | 可借用 |
| 维护中 | - | - |

## 八、接口调用注意事项

### 8.1 参数传递规范

1. **枚举类型参数**：前端传递中文值即可，后端支持自动转换（如 `行车组`、`可借用`、`支持全部测试`）
2. **日期格式**：统一使用 `YYYY-MM-DD` 格式
3. **分页参数**：`skip` 表示跳过的记录数，`limit` 表示每页条数，默认分页大小为 100
4. **模糊查询**：`model`、`vin_code`、`driver_name` 等参数支持模糊匹配

### 8.2 字符编码

前端传递中文参数时，URL 会自动进行 UTF-8 编码（如 `测试状态=%E6%94%AF%E6%8C%81%E5%85%A8%E9%83%A8%E6%B5%8B%E8%AF%95`），后端会自动解码处理。

### 8.3 高级查询操作符

| 操作符 | 说明 | 适用字段类型 |
|--------|------|-------------|
| contains | 包含匹配（like %value%） | string |
| equals | 精确等于 | 所有类型 |
| notEquals | 不等于 | 所有类型 |
| startsWith | 开头匹配（like value%） | string |
| endsWith | 结尾匹配（like %value） | string |
