# 车辆管理插件接口文档

---

## 一、接口总览

### 1.1 车辆管理接口（前缀：`/api/vehicle`）

| 接口路径 | 方法 | 说明 |
|---------|------|------|
| `/api/vehicle/stats` | GET | 获取车辆统计信息 |
| `/api/vehicle/advsearch` | POST | 车辆高级查询 |
| `/api/vehicle/fixsearch` | GET | 车辆固定字段查询 |
| `/api/vehicle/createvehicle` | POST | 创建车辆 |
| `/api/vehicle/getstatus/{vehicle_id}` | GET | 获取车辆状态 |
| `/api/vehicle/getvehicle/{vehicle_id}` | GET | 获取单个车辆信息 |
| `/api/vehicle/updatevehicle/{vehicle_id}` | PUT | 更新车辆信息 |
| `/api/vehicle/delvehicle/{vehicle_id}` | DELETE | 删除车辆 |

### 1.2 借用管理接口（前缀：`/api/borrow`）

| 接口路径 | 方法 | 说明 |
|---------|------|------|
| `/api/borrow/stats` | GET | 获取借用统计信息 |
| `/api/borrow/fixsearch` | GET | 借用记录固定字段查询 |
| `/api/borrow/advsearch` | POST | 借用记录高级查询 |
| `/api/borrow/createborrow` | POST | 创建借用记录 |
| `/api/borrow/getborrow/{record_id}` | GET | 获取单个借用记录 |
| `/api/borrow/updateborrow/{record_id}` | PUT | 更新借用记录 |
| `/api/borrow/delborrow/{record_id}` | DELETE | 删除借用记录 |
| `/api/borrow/returnvehicle/{record_id}` | POST | 归还车辆 |
| `/api/borrow/cancelborrow/{record_id}` | POST | 取消借用 |

---

## 二、统一响应格式

所有接口均采用以下统一响应格式：

```json
{
    "code": 200,
    "message": "success",
    "data": <业务数据或null>
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码，200表示成功，400表示失败 |
| message | string | 响应消息 |
| data | object/array/null | 业务数据，失败时为null |

## 三、车辆管理接口详情

### 3.1 获取车辆统计信息

**接口路径：** `/api/vehicle/stats`

**请求方法：** `GET`

**请求参数：** 无

**请求示例：**
```
GET /api/vehicle/stats
```

**成功响应：**

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "total": 50,
        "available": 30,
        "borrowed": 15,
        "maintenance": 5
    }
}
```

**响应字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| total | int | 车辆总数 |
| available | int | 可用车辆数 |
| borrowed | int | 已借出车辆数 |
| maintenance | int | 维护中车辆数 |

### 3.2 车辆高级查询

**接口路径：** `/api/vehicle/advsearch`

**请求方法：** `POST`

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| skip | int | Query | 否 | 0 | 跳过记录数（≥0） |
| limit | int | Query | 否 | 100 | 返回记录数（1-1000） |
| conditions | List[dict] | Body | 是 | - | 高级查询条件列表 |

**conditions 条件格式：**

```json
[
    {
        "advanced_field": "字段名",
        "advanced_operator": "操作符",
        "advanced_value": "值"
    }
]
```

| 字段 | 说明 |
|------|------|
| advanced_field | 查询字段，必须在 VEHICLE_WHITELIST 中 |
| advanced_operator | 操作符，必须在系统支持的 ADVANCED_OPERATORS 中（如 eq、contains 等） |
| advanced_value | 查询值 |

**可查询字段（advanced_field）：**

id、model、vehicle_code、vin_code、owner_name、plate_number、editor、group、vehicle_status、test_status、vehicle_stage、configuration、parking_location、engine_num、temp_plate_expire_date、temp_plate_count、remarks、created_at、updated_at

**请求示例：**
```
POST /api/vehicle/advsearch?skip=0&limit=10
```
```json
[
    {
        "advanced_field": "vehicle_status",
        "advanced_operator": "eq",
        "advanced_value": "available"
    },
    {
        "advanced_field": "model",
        "advanced_operator": "contains",
        "advanced_value": "Model"
    }
]
```

**成功响应：**

```json
{
    "code": 200,
    "message": "success",
    "data": [
        {
            "id": 1,
            "model": "Model X",
            "vehicle_code": "VH001",
            "vin_code": "LSVAU2180N2123456",
            "owner_name": "张三",
            "plate_number": "京A12345",
            "editor": "管理员",
            "group": "driving_group",
            "vehicle_status": "available",
            "test_status": "支持全部测试",
            "vehicle_stage": "量产",
            "configuration": "高配",
            "parking_location": "A区1号",
            "engine_num": "ENG001",
            "temp_plate_expire_date": "2025-06-30",
            "temp_plate_count": 1,
            "remarks": null,
            "created_at": "2025-01-15T10:30:00",
            "updated_at": "2025-01-15T10:30:00"
        }

}
```

**错误响应：**

| code | message | 说明 |
|------|---------|------|
| 400 | Invalid advanced conditions | conditions 为空 |
| 400 | Invalid advanced_field: xxx | 字段不在白名单中 |

### 3.4 创建车辆

**接口路径：** `/api/vehicle/createvehicle`

**请求方法：** `POST`

**请求参数（Body - JSON）：**

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| model | string(max=100) | 是 | - | 车型 |
| vehicle_code | string(max=50) | 是 | - | 车辆编号（唯一） |
| vin_code | string(max=17) | 是 | - | VIN码（唯一） |
| owner_name | string(max=100) | 是 | - | 车主权限 |
| plate_number | string(max=20) | 是 | - | 车牌号 |
| editor | string(max=20) | 是 | - | 最后编辑人 |
| group | VehicleGroup | 否 | None | 组别 |
| vehicle_status | VehicleStatus | 否 | None | 车辆状态 |
| test_status | TestStatus | 否 | None | 测试状态 |
| vehicle_stage | string(max=20) | 否 | None | 车辆阶段 |
| configuration | string(max=200) | 否 | None | 车辆配置 |
| parking_location | string(max=200) | 否 | None | 停车地点 |
| engine_num | string(max=100) | 否 | None | 驱动电机号/发动机号 |
| temp_plate_expire_date | date | 否 | None | 临牌到期时间 |
| temp_plate_count | int | 否 | 0 | 临牌已办理次数 |
| remarks | string | 否 | None | 备注 |

**group 枚举值：** `driving_group`、`parking_group`、`warning_group`

**vehicle_status 枚举值：** `available`、`borrowed`、`maintenance`

**test_status 枚举值：** `支持全部测试`、`不支持泊车测试`、`不支持行车测试`、`不支持后向预警测试`、`不支持全部测试`、`生产中`、`外借中`

**请求示例：**
```json
{
    "model": "Model X",
    "vehicle_code": "VH001",
    "vin_code": "LSVAU2180N2123456",
    "owner_name": "张三",
    "plate_number": "京A12345",
    "editor": "管理员",
    "group": "driving_group",
    "vehicle_status": "available",
    "test_status": "支持全部测试",
    "vehicle_stage": "量产",
    "configuration": "高配",
    "parking_location": "A区1号",
    "engine_num": "ENG001",
    "temp_plate_expire_date": "2025-06-30",
    "temp_plate_count": 1,
    "remarks": "测试车辆"
}
```

**成功响应：**

```json
{
    "code": 200,
    "message": "Vehicle created successfully",
    "data": null
}
```

**错误响应：**

| code | message | 说明 |
|------|---------|------|
| 400 | Vehicle code is missing | 车辆编号为空 |
| 400 | VIN code is missing | VIN码为空 |
| 400 | Model is missing | 车型为空 |
| 400 | Owner name is missing | 车主权限为空 |
| 400 | Plate number is missing | 车牌号为空 |
| 400 | Editor is missing | 编辑人为空 |
| 400 | vehicle_code already exists | 车辆编号已存在 |
| 400 | vin_code already exists | VIN码已存在 |

### 3.7 更新车辆信息

**接口路径：** `/api/vehicle/updatevehicle/{vehicle_id}`

**请求方法：** `PUT`

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 说明 |
|--------|------|------|------|------|
| vehicle_id | int | Path | 是 | 车辆ID |

**Body 参数（JSON，所有字段均为可选，仅传入需更新的字段）：**

| 参数名 | 类型 | 说明 |
|--------|------|------|
| model | Optional[string(max=100)] | 车型 |
| group | Optional[VehicleGroup] | 组别 |

| vin_code | Optional[string(max=17)] | VIN码 |
| owner_name | Optional[string(max=100)] | 车主权限 |
| plate_number | Optional[string(max=20)] | 车牌号 |
| vehicle_stage | Optional[string(max=20)] | 车辆阶段 |
| configuration | Optional[string(max=200)] | 车辆配置 |
| parking_location | Optional[string(max=200)] | 停车地点 |
| vehicle_status | Optional[VehicleStatus] | 车辆状态 |
| test_status | Optional[TestStatus] | 测试状态 |
| engine_num | Optional[string(max=100)] | 驱动电机号/发动机号 |
| temp_plate_expire_date | Optional[date] | 临牌到期时间 |
| temp_plate_count | Optional[int] | 临牌已办理次数 |
| editor | Optional[string(max=20)] | 最后编辑人 |
| remarks | Optional[string] | 备注 |

**请求示例：**
```
PUT /api/vehicle/updatevehicle/1
```
```json
{
    "vehicle_status": "maintenance",
    "parking_location": "B区3号",
    "remarks": "定期保养中"
}
```

**成功响应：**

```json
{
    "code": 200,
    "message": "Vehicle updated successfully",
    "data": null
}
```

**错误响应：**

| code | message | 说明 |
|------|---------|------|
| 400 | Vehicle not found | 车辆不存在 |
| 400 | vehicle_code already exists | 车辆编号已存在（如更新了vehicle_code） |
| 400 | vin_code already exists | VIN码已存在（如更新了vin_code） |

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|

| vin_code | string(max=17) | 是 | - | VIN码 |
| borrower | string(max=100) | 是 | - | 借用人 |
| borrow_time | date | 是 | - | 借用时间 |

| remarks | string | 否 | None | 备注 |

> **业务说明：** 创建借用记录时，系统会自动将关联车辆的状态更新为 `borrowed`（已借出）。

## 五、业务流程说明

### 5.1 车辆借用-归还流程

```
车辆可用(available)
    │
    ▼
创建借用记录 ───────────► 车辆状态变为已借出(borrowed)
    │                         │
    │                         ▼
    │                    归还车辆(returnvehicle) ──► 车辆恢复可用(available)
    │                    借用记录变为已归还(returned)
    │
    │
    └──► 取消借用(cancelborrow) ──► 车辆恢复可用(available)
                                  借用记录变为已取消(cancelled)
```

### 5.2 状态变更规则

| 当前车辆状态 | 可执行操作 | 变更后状态 |
|-------------|-----------|-----------|
| available | 创建借用记录 | borrowed |
| borrowed | 归还车辆 | available |
| borrowed | 取消借用 | available |
| maintenance | - | - |
