# 车辆插件数据字典

## 一、Vehicle 车辆表

| 字段名 | 数据库类型 | Pydantic类型 | 约束 | 中文说明 |
|--------|-----------|-------------|------|----------|
| id | Integer | int | 主键、自增 | 车辆ID |
| model | String(100) | str | 非空 | 车型 |
| group | Enum(VehicleGroup) | VehicleGroup | 默认 driving_group | 组别 |
| vehicle_stage | String(20) | Optional[str] | 可空 | 车辆阶段 |
| configuration | String(200) | Optional[str] | 可空 | 车辆配置 |
| owner_name | String(100) | str | 非空 | 车主权限 |
| vehicle_code | String(50) | str | 唯一、非空、索引 | 车辆编号 |
| parking_location | String(200) | Optional[str] | 可空 | 停车地点 |
| vehicle_status | Enum(VehicleStatus) | VehicleStatus | 默认 available | 车辆状态 |
| test_status | Enum(TestStatus) | TestStatus | 默认 支持全部测试 | 测试状态 |
| remarks | Text | Optional[str] | 可空 | 备注 |
| vin_code | String(17) | str | 唯一、非空、索引 | VIN码 |
| engine_num | String(100) | Optional[str] | 可空 | 驱动电机号/发动机号 |
| plate_number | String(20) | str | 非空 | 车牌号 |
| temp_plate_expire_date | Date | Optional[date] | 可空 | 临牌到期时间 |
| temp_plate_count | Integer | int | 默认0 | 临牌已办理次数 |
| editor | String(20) | str | 非空 | 最后编辑人 |
| created_at | DateTime | datetime | 自动生成 | 创建时间 |
| updated_at | DateTime | datetime | 自动更新 | 最后编辑时间 |

## 二、BorrowRecord 借用记录表

| 字段名 | 数据库类型 | Pydantic类型 | 约束 | 中文说明 |
|--------|-----------|-------------|------|----------|
| id | Integer | int | 主键、自增 | 记录ID |
| model | String(100) | Optional[str] | 可空 | 车型 |
| vehicle_id | Integer | int | 外键、非空 | 车辆ID |
| vehicle_code | String(50) | Optional[str] | 可空 | 车辆编号 |
| vin_code | String(17) | str | 唯一、非空、索引 | VIN码 |
| borrower | String(100) | str | 非空 | 借用人 |
| borrow_time | Date | date | 非空 | 借用时间 |
| driver_name | String(100) | Optional[str] | 可空 | 司机姓名 |
| driver_work | String(50) | Optional[str] | 可空 | 司机工作安排 |
| driver_performance | String(100) | Optional[str] | 可空 | 司机绩效（有效工时+有效里程） |
| record_creator | String(50) | Optional[str] | 可空 | 记录创建人 |
| created_at | Date | date | 自动生成 | 创建时间 |
| status | String(20) | Optional[str] | 默认 active | 借用状态 |
| updated_at | Date | date | 自动更新 | 最后编辑时间 |
| remarks | Text | Optional[str] | 可空 | 备注 |

## 三、枚举值说明

### VehicleStatus 车辆状态

| 枚举值 | 中文说明 |
|--------|----------|
| AVAILABLE | 可用 |
| BORROWED | 已借出 |
| MAINTENANCE | 维护中 |

### VehicleGroup 车辆组别

| 枚举值 | 中文说明 |
|--------|----------|
| DRIVEING | 行车组 |
| PARKING | 泊车组 |
| WARNNING | 预警组 |

### TestStatus 测试状态

| 枚举值 | 中文说明 |
|--------|----------|
| ALL_SUPPORT | 支持全部测试 |
| NO_PARKING | 不支持泊车测试 |
| NO_DRIVING | 不支持行车测试 |
| NO_BACKWARNING | 不支持后向预警测试 |
| NO_SUPPORT | 不支持全部测试 |
| PRODUCING | 生产中 |
| BORROWING | 外借中 |

### BorrowStatus 借用状态

| 枚举值 | 中文说明 |
|--------|----------|
| active | 借用中 |
| returned | 已归还 |
| cancelled | 已取消 |

## 四、高级搜索操作符

| 操作符 | SQL含义 | 说明 |
|--------|--------|------|
| eq | WHERE field = value | 精确等于 |
| ne | WHERE field != value | 不等于 |
| contains | WHERE field.contains(value) | 包含（区分大小写） |
| icontains | WHERE field ILIKE '%value%' | 包含（不区分大小写） |
| gt | WHERE field > value | 大于 |
| gte | WHERE field >= value | 大于等于 |
| lt | WHERE field < value | 小于 |
| lte | WHERE field <= value | 小于等于 |
