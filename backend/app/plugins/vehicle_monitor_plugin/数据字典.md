# 车辆监控插件 - 数据字典

## 模块概述

- **模块名称**: vehicle_monitor_plugin
- **插件版本**: 1.0.0
- **路由前缀**: `/api/vehicle_monitor`
- **功能描述**: 车辆监控数据管理，包含测试车辆的上电时间、使用率、里程等监控指标的 CRUD 操作。

---

## 数据库表: `vehicle_monitors`

**表说明**: 车辆监控记录表，存储每台测试车辆每日的监控数据。

| 序号 | 字段名 | 数据类型 | 允许为空 | 默认值 | 说明 |
|------|--------|----------|----------|--------|------|
| 1 | `id` | `Integer` | 否 | 自增 | 主键ID，自动递增 |
| 2 | `monitor_date` | `Date` | 是 | NULL | 监控日期 |
| 3 | `vin_code` | `String(17)` | 否 | - | 测试车辆VIN号（17位），唯一索引 |
| 4 | `power_duration` | `DECIMAL(10, 2)` | 是 | NULL | 车辆上电时间，单位：小时 |
| 5 | `usage` | `DECIMAL(10, 4)` | 是 | NULL | 车辆使用率，精度4位小数 |
| 6 | `distance` | `DECIMAL(10, 2)` | 是 | NULL | 车辆行驶里程 |
| 7 | `is_del` | `Boolean` | 是 | `False` | 逻辑删除标记，`True` 表示已删除 |
| 8 | `create_time` | `DateTime` | 是 | `now()` | 记录创建时间，由数据库自动生成 |
| 9 | `update_time` | `DateTime` | 是 | `now()` | 记录更新时间，更新时自动刷新 |

---

## 索引说明

| 索引字段 | 索引类型 | 说明 |
|----------|----------|------|
| `id` | PRIMARY KEY | 主键索引 |
| `vin_code` | UNIQUE INDEX | 唯一索引，确保 VIN 号不重复 |

---

## 字段约束与业务规则

| 规则 | 说明 |
|------|------|
| VIN码唯一性 | `vin_code` 字段有唯一约束，同一 VIN 号不可重复录入 |
| 逻辑删除 | 删除操作不物理删除数据，仅将 `is_del` 置为 `True` |
| 查询过滤 | 所有查询接口默认过滤 `is_del = True` 的记录（即只返回未删除数据） |
| 时间戳 | `create_time` 和 `update_time` 由数据库自动维护，无需手动传入 |

---

## ORM 模型

**类名**: `VehicleMonitor`  
**所在文件**: `models.py`  
**基类**: `app.core.database.Base`

```python
class VehicleMonitor(Base):
    __tablename__ = "vehicle_monitors"
    id = Column(Integer, primary_key=True, index=True)
    monitor_date = Column(Date)
    vin_code = Column(String(17), unique=True, index=True, nullable=False)
    power_duration = Column(DECIMAL(10, 2))
    usage = Column(DECIMAL(10, 4))
    distance = Column(DECIMAL(10, 2))
    is_del = Column(Boolean, default=False)
    create_time = Column(DateTime, server_default=func.now())
    update_time = Column(DateTime, server_default=func.now(), onupdate=func.now())
```
