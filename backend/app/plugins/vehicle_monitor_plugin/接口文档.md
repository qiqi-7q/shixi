# 车辆监控插件 - 接口文档

## 模块概述

- **模块名称**: vehicle_monitor_plugin
- **插件版本**: 1.0.0
- **路由前缀**: `/api/vehicle_monitor`
- **功能描述**: 车辆监控数据管理，提供车辆监控记录的增删改查接口。

---

## 通用说明

### 基础路径

```
/api/vehicle_monitor
```

### 通用响应格式

所有接口统一返回以下 JSON 格式：

```json
{
  "data": "数据内容（可为 null、对象或列表）",
  "message": "状态描述信息",
  "code": 200
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `data` | `any` | 响应数据，成功时返回对应数据，失败时为 `null` |
| `message` | `string` | 状态描述，成功时为 `"success"` 或 `"数据创建成功"` 等 |
| `code` | `int` | 状态码，`200` 表示成功，`400` 表示失败 |

### 通用错误码

| code | 说明 |
|------|------|
| 200 | 请求成功 |
| 400 | 请求失败（参数校验失败、数据不存在、数据库异常等） |

## 接口列表

---

### 1. 创建车辆监控记录

**接口描述**: 新增一条车辆监控记录。

**请求信息**

| 项目 | 值 |
|------|-----|
| 请求方式 | `POST` |
| 请求路径 | `/api/vehicle_monitor/create` |
| Content-Type | `application/json` |

**请求参数 (Body - JSON)**

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `monitor_date` | `string` (date) | 否 | 监控日期，格式: `YYYY-MM-DD` |
| `vin_code` | `string` | 否 | 测试车辆VIN号，最大长度17位 |
| `power_duration` | `number` (decimal) | 否 | 车辆上电时间，单位：小时 |
| `usage` | `number` (decimal) | 否 | 车辆使用率 |
| `distance` | `number` (decimal) | 否 | 车辆行驶里程 |

**请求示例**

```json
{
  "monitor_date": "2026-06-25",
  "vin_code": "LSVAU2A32N2100001",
  "power_duration": 8.50,
  "usage": 0.8500,
  "distance": 120.00
}
```

**成功响应示例**

```json
{
  "message": "数据创建成功",
  "code": 200,
  "data": null
}
```

**失败响应示例**

```json
{
  "message": "创建车辆监测数据失败: VIN码已存在",
  "code": 400,
  "data": null
}
```

### 2. 查询车辆监控列表

**接口描述**: 分页查询车辆监控记录列表，可按 VIN 码模糊搜索。

**请求信息**

| 项目 | 值 |
|------|-----|
| 请求方式 | `GET` |
| 请求路径 | `/api/vehicle_monitor/fixsearch` |

**请求参数 (Query)**

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `skip` | `int` | 否 | `0` | 跳过的记录数（分页偏移量） |
| `limit` | `int` | 否 | `100` | 每页返回的最大记录数 |
| `vin_code` | `string` | 否 | - | VIN 号模糊搜索关键字 |

**请求示例**

```
GET /api/vehicle_monitor/fixsearch?skip=0&limit=10&vin_code=LSV
```

**成功响应示例**

```json
{
  "data": {
    "items": [
      {
        "id": 1,
        "monitor_date": "2026-06-25",
        "vin_code": "LSVAU2A32N2100001",
        "power_duration": 8.50,
        "usage": 0.8500,
        "distance": 120.00,
        "is_del": false,
        "create_time": "2026-06-25T10:00:00",
        "update_time": "2026-06-25T10:00:00"
      }
    ],
    "total": 1,
    "skip": 0,
    "limit": 10
  },
  "message": "success",
  "code": 200
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| `data.items` | `array` | 车辆监控记录列表 |
| `data.total` | `int` | 符合条件的总记录数 |
| `data.skip` | `int` | 当前偏移量 |
| `data.limit` | `int` | 当前页大小 |

### 5. 删除车辆监控记录

**接口描述**: 根据 ID 逻辑删除车辆监控记录（将 `is_del` 标记为 `True`，不物理删除）。

**请求信息**

| 项目 | 值 |

| 请求路径 | `/api/vehicle_monitor/delmonitor/{monitor_id}` |

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `monitor_id` | `int` | 是 | 车辆监控记录 ID |

**请求示例**

```
DELETE /api/vehicle_monitor/delmonitor/1
```

```json
{
  "message": "数据删除成功",
  "code": 200,
  "data": null
```

## 接口汇总

| 序号 | 接口名称 | 请求方式 | 请求路径 | 说明 |
|------|----------|----------|----------|------|
| 1 | 创建记录 | `POST` | `/api/vehicle_monitor/create` | 新增车辆监控记录 |
| 2 | 查询列表 | `GET` | `/api/vehicle_monitor/fixsearch` | 分页查询，支持 VIN 模糊搜索 |
| 3 | 获取详情 | `GET` | `/api/vehicle_monitor/getmonitor/{id}` | 根据 ID 获取单条记录 |
| 4 | 更新记录 | `PUT` | `/api/vehicle_monitor/updatemonitor/{id}` | 部分更新记录字段 |
| 5 | 删除记录 | `DELETE` | `/api/vehicle_monitor/delmonitor/{id}` | 逻辑删除记录 |

---

## 注意事项

1. **逻辑删除**: 删除操作为逻辑删除，不会真正从数据库中移除数据。
2. **VIN 码唯一**: `vin_code` 字段在数据库层面有唯一约束，重复录入会触发异常。
3. **部分更新**: 更新接口只更新请求体中传入的字段，未传入的字段保持原值不变。
4. **查询过滤**: 列表和详情接口均自动过滤已删除（`is_del = True`）的记录。
5. **时间字段**: `create_time` 和 `update_time` 由数据库自动维护，接口请求和响应中均为只读字段。
