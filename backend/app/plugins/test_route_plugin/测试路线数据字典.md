# 测试路线插件数据字典

---

## 一、枚举类型定义

当前模块**未定义任何枚举类型**。所有字段均使用字符串或数值类型。

---

## 二、test_routes 测试路线表

### 2.1 表结构

| 字段名 | 数据库类型 | Pydantic类型 | 长度/精度 | 必填 | 默认值 | 约束 | 中文说明 |
|--------|-----------|-------------|-----------|------|--------|------|----------|
| id | Integer | int | - | 是 | 自增 | 主键、索引 | 主键ID |
| location | String | str | 100 | 是 | - | 非空 | 地点 |
| route_name | String | str | 100 | 是 | - | 非空 | 路线名称 |
| route_length | DECIMAL | Decimal | (10,1) | 是 | - | 非空 | 路线里程（单位：km） |
| diff | DECIMAL | Decimal | (3,0) | 是 | - | 非空 | 难度系数（0-100） |
| test_func | String | str | 100 | 是 | - | 非空 | 测试功能 |
| route_desc | Text | Optional[str] | - | 否 | - | 可空 | 路线描述 |
| route_feature | String | Optional[str] | 200 | 否 | - | 可空 | 路线特征 |
| route_link | String | Optional[str] | 500 | 否 | - | 可空 | 路线链接 |
| remark | Text | Optional[str] | - | 否 | - | 可空 | 备注 |
| creator | String | str | 50 | 是 | - | 非空 | 创建人 |
| create_time | DateTime | datetime | - | 否 | now() | 自动生成 | 创建时间 |
| update_time | DateTime | datetime | - | 否 | now() | 自动更新 | 更新时间 |

### 2.2 索引

| 索引类型 | 字段 | 说明 |
|---------|------|------|
| 主键索引 | id | 自增主键 |

### 2.3 字段值域说明

| 字段 | 值域/约束 | 说明 |
|------|----------|------|
| route_length | DECIMAL(10,1)，必须 > 0 | 路线里程，精度为 10 位整数 + 1 位小数，如 `12.3` |
| diff | DECIMAL(3,0)，范围 0 - 100 | 难度系数，整数类型，如 `75` |

## 四、Schema 模型说明

| 字段名 | 类型 | 必填 | 默认值 | 说明 |

| route_length | Optional[Decimal] | 否 | None | 路线里程 |

| remark | Optional[str] | 否 | None | 备注 |
| creator | Optional[str] (max=50) | 否 | None | 创建人 |

### 4.4 TestRouteResponse 测试路线响应模型

继承自 TestRouteBase，额外包含数据库自动生成的字段。

| 字段名 | 类型 | 说明 |
|--------|------|------|
| （继承 TestRouteBase 所有字段） | - | - |
| id | int | 主键ID |
| create_time | datetime | 创建时间 |
| update_time | datetime | 更新时间 |

> 配置 `model_config = ConfigDict(from_attributes=True)`，支持从 ORM 模型直接转换。

### 4.5 TestRouteBatchImport 批量导入模型

当前模型定义为 `pass`（未实现），预留用于批量导入功能扩展。

## 五、业务校验规则说明

### 5.1 创建测试路线校验规则

| 校验项 | 校验规则 | 错误信息 | 说明 |
|--------|---------|---------|------|
| location | 非空 | location is empty | 地点必填 |
| route_name | 非空 | route_name is empty | 路线名称必填 |
| route_length | 非空 | route_length is empty | 路线里程必填 |
| route_length | > 0 | route_length must be greater than 0 | 里程必须大于0 |
| diff | 非空 | diff is empty | 难度系数必填 |
| diff | 0 - 100 | diff must be between 0 and 100 | 难度系数范围 0-100 |
| test_func | 非空 | test_func is empty | 测试功能必填 |
| creator | 非空 | creator is empty | 创建人必填 |

### 5.2 更新测试路线校验规则

| 校验项 | 校验规则 | 错误信息 | 说明 |
|--------|---------|---------|------|
| 路线存在性 | 记录必须存在 | route not found | 更新的路线必须存在 |
| location | 非空 | location is empty | 地点必填 |
| route_name | 非空 | route_name is empty | 路线名称必填 |
| route_length | 非空 | route_length is empty | 路线里程必填 |
| route_length | > 0 | route_length must be greater than 0 | 里程必须大于0 |
| diff | 非空 | diff is empty | 难度系数必填 |
| diff | 0 - 100 | diff must be between 0 and 100 | 难度系数范围 0-100 |
| test_func | 非空 | test_func is empty | 测试功能必填 |
| creator | 非空 | creator is empty | 创建人必填 |

> **注意：** 更新时校验规则对必填字段会先检查是否为 `None` 或空字符串，使用 `exclude_unset=True` 进行部分更新，但校验函数会对**所有字段（包括未传入的）**进行检查，可能触发误报。建议在实际使用中确保所有必填字段在请求体中均有值。
