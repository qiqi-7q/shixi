# 测试路线插件接口文档

---

## 一、接口总览

所有接口前缀：`/api/test_route`

| 接口路径                                     | 方法     | 说明             |
|------------------------------------------|--------|----------------|
| `/api/test_route/createroute`            | POST   | 创建单条测试路线       |
| `/api/test_route/fixsearch`              | GET    | 获取路线列表（固定字段查询） |
| `/api/test_route/getroute/{route_id}`    | GET    | 获取单条路线详情       |
| `/api/test_route/updateroute/{route_id}` | PUT    | 更新路线信息         |
| `/api/test_route/delroute/{route_id}`    | DELETE | 删除路线           |

---

## 二、统一响应格式

所有接口均采用以下统一响应格式：

```json
{
  "code": 200,
  "message": "success",
  "data": <业务数据或null>,
  "skip": 0,
  "limit": 100
}
```

| 字段      | 类型                | 说明                    |
|---------|-------------------|-----------------------|
| code    | int               | 状态码，200 表示成功，400 表示失败 |
| message | string            | 响应消息                  |
| data    | object/array/null | 业务数据，失败时为 null        |
| skip    | int               | 跳过的记录数（列表接口返回）      |
| limit   | int               | 返回的记录数（列表接口返回）      |

---

## 三、接口详情

### 3.1 创建单条测试路线

**接口路径：** `/api/test_route/createroute`

**请求方法：** `POST`

**请求参数（Body - JSON）：**

| 参数名           | 类型               | 必填 | 默认值  | 说明              |
|---------------|------------------|----|------|-----------------|
| route_name    | string (max=100) | 是  | -    | 路线名称            |
| route_length  | Decimal          | 是  | -    | 路线里程（必须 > 0）    |
| test_func     | string (max=100) | 是  | -    | 测试功能            |
| diff          | int              | 是  | -    | 难度系数（0 - 100） |
| creator       | string (max=50)  | 是  | -    | 创建人             |
| route_desc    | string           | 否  | None | 路线描述            |
| route_feature | string (max=200) | 否  | None | 路线特征            |
| route_link    | string (max=500) | 否  | None | 路线链接            |
| remark        | string           | 否  | None | 备注              |

**字段值域说明：**

| 字段           | 约束                        | 说明                      |
|--------------|---------------------------|-------------------------|
| route_length | DECIMAL(10,1)，必须 > 0      | 里程数值，精度为 10 位整数 + 1 位小数 |
| diff         | int，范围 0 - 100 | 难度系数，整数类型 |

**请求示例：**

```
POST /api/test_route/createroute
```

```json
{
  "route_name": "北京环路测试路线A",
  "route_length": 52.5,
  "test_func": "行车辅助驾驶",
  "diff": 75,
  "creator": "张三",
  "route_desc": "五环外环测试路段",
  "route_feature": "弯道、高速、匝道",
  "route_link": "https://maps.example.com/route/001",
  "remark": "适用于高速场景测试"
}
```

**成功响应：**

```json
{
  "code": 200,
  "message": "route created successfully",
  "data": null,
  "skip": 0,
  "limit": 100
}
```

**错误响应：**

| code | message                             | 说明            |
|------|-------------------------------------|---------------|
| 400  | route_name is empty                 | 路线名称为空        |
| 400  | route_length is empty               | 路线里程为空        |
| 400  | route_length must be greater than 0 | 里程必须大于 0      |
| 400  | diff is empty                       | 难度系数为空        |
| 400  | diff must be between 0 and 100        | 难度系数超出 0-100 范围 |
| 400  | test_func is empty                  | 测试功能为空        |
| 400  | creator is empty                    | 创建人为空         |

### 3.2 获取路线列表（固定字段查询）

**接口路径：** `/api/test_route/fixsearch`

**请求方法：** `GET`

**请求参数：**

| 参数名           | 类型     | 位置    | 必填 | 默认值  | 查询方式           | 说明        |
|---------------|--------|-------|----|------|----------------|-----------|
| skip          | int    | Query | 否  | 0    | -              | 跳过记录数（≥0） |
| limit         | int    | Query | 否  | 100  | -              | 返回记录数     |
| route_name    | string | Query | 否  | None | 模糊匹配（contains） | 路线名称      |
| route_desc    | string | Query | 否  | None | 模糊匹配（contains） | 路线描述      |
| route_feature | string | Query | 否  | None | 模糊匹配（contains） | 路线特征      |
| creator       | string | Query | 否  | None | 模糊匹配（contains） | 创建人       |

**请求示例：**

```
GET /api/test_route/fixsearch?skip=0&limit=10&route_name=环路&creator=张三
```

**成功响应：**


### 3.4 更新路线信息

**接口路径：** `/api/test_route/updateroute/{route_id}`

**请求方法：** `PUT`

**请求参数：**

| 参数名      | 类型  | 位置   | 必填 | 说明       |
|----------|-----|------|----|----------|
| route_id | int | Path | 是  | 路线ID（主键） |

**Body 参数（JSON，所有字段均为可选，仅传入需更新的字段）：**

| 参数名           | 类型               | 必填 | 默认值  | 说明              |
|---------------|------------------|----|------|-----------------|
| route_name    | string (max=100) | 否  | None | 路线名称            |
| route_length  | Decimal          | 否  | None | 路线里程（必须 > 0）    |
| test_func     | string (max=100) | 否  | None | 测试功能            |
| diff          | int              | 否  | None | 难度系数（0 - 100） |
| route_desc    | string           | 否  | None | 路线描述            |
| route_feature | string (max=200) | 否  | None | 路线特征            |
| route_link    | string (max=500) | 否  | None | 路线链接            |
| remark        | string           | 否  | None | 备注              |
| creator       | string (max=50)  | 否  | None | 创建人             |

>
**请求示例：**

```
PUT /api/test_route/updateroute/1
```

```json
{
  "route_name": "北京环路测试路线A（更新）",
  "route_length": 55.0,
  "test_func": "行车辅助驾驶",
  "diff": 4.0,
  "creator": "李四",
  "remark": "已更新里程数据"
}
```

**成功响应：**

```json
{
  "code": 200,
  "message": "route updated successfully",
  "data": null,
  "skip": 0,
  "limit": 100
}
```

**错误响应：**

| code | message                             | 说明                 |
|------|-------------------------------------|--------------------|
| 400  | route not found                     | 指定 route_id 的路线不存在 |
| 400  | route_name is empty                 | 路线名称为空             |
| 400  | route_length is empty               | 路线里程为空             |
| 400  | route_length must be greater than 0 | 里程必须大于 0           |
| 400  | diff is empty                       | 难度系数为空             |
| 400  | diff must be between 0 and 5        | 难度系数超出 0-5 范围      |
| 400  | test_func is empty                  | 测试功能为空             |
| 400  | creator is empty                    | 创建人为空              |
