### 2.2 索引

| 索引类型 | 字段            | 说明       |
|------|---------------|----------|
| 主键索引 | id            | 自增主键     |
| 普通索引 | function_mode | 功能模式查询   |
| 普通索引 | vin_code      | 车辆VIN号查询 |

### 2.3 字段业务说明

| 字段                 | 取值说明                | 备注             |
|--------------------|---------------------|----------------|
| problem_category   | 可靠性、法规安全、舒适性、可用性、其他 | 评价维度，对应问题大类打分  |
| kpi_type           | 自定义KPI指标项           | 新增的KPI项字段，用于打分 |
| problem_scene      | 一级场景分类              | 问题场景对应一级分类     |
| problem_phenomenon | 四级现象分类              | 问题现象对应四级分类     |

### 2.4 批量导入去重规则

批量导入时，通过以下字段组合判定数据是否重复：

| 字段组合                                   | 说明          |
|----------------------------------------|-------------|
| vin_code + problem_time + problem_desc | 三者均相同视为重复数据 |

> 此规则由 `REPEAT_CHECK_FIELDS` 配置定义，可根据业务需求调整。

| 校验项          | 校验规则 | 错误信息                    | 说明       |

| 校验项   | 校验规则               | 错误信息             | 说明             |

## 五、批量导入处理流程

```
Excel文件（本地绝对路径）
    │
    ▼
读取Sheet1 ──── 过滤全空行 ──── 处理表头（空值/重名）
    │
    ▼
第一重去重：内存去重（基于 vin_code + problem_time + problem_desc）
    │           过滤Excel内部的重复数据
    ▼
第二重去重：数据库去重（基于相同字段组合）
    │           过滤数据库中已存在的重复数据
    ▼
数据校验：转Pydantic模型，确保格式符合Schema
    │
    ▼
批量写入数据库（bulk_insert_mappings）
    │
    ▼
返回导入结果统计
```

**导入结果返回字段：**

| 字段                   | 类型     | 说明              |
|----------------------|--------|-----------------|
| msg                  | string | 导入结果消息          |
| total_excel_rows     | int    | Excel读取的有效数据总行数 |
| excel_duplicate_rows | int    | Excel内过滤的重复行数   |
| db_duplicate_rows    | int    | 数据库已存在的重复行数     |
| success_import_rows  | int    | 最终成功导入的新数据行数    |
| failed_import_rows   | int    | 导入失败的行数         |

## 六、Excel 文件规范

### 6.1 文件格式要求

| 要求项  | 说明             |
|------|----------------|
| 文件格式 | `.xlsx`        |
| 工作表名 | `Sheet1`（默认读取） |
| 表头行  | 第 1 行为表头       |
| 数据行  | 第 2 行起为数据      |
| 空行处理 | 全空行自动过滤        |

| kpi_type           | KPI项                   | 否    |
| problem_scene      | 问题场景                   | 否    |
| problem_type       | 问题分类                   | 否    |
| problem_phenomenon | 问题现象                   | 否    |
| takeover_type      | 接管类型                   | 否    |
| problem_time       | 问题时间                   | 是    |
| vin_code           | 车辆VIN号                 | 是    |
