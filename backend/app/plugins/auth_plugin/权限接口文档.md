# 认证插件接口文档

---

## 一、接口总览

| 接口路径 | 方法 | 说明 | 认证 |
|---------|------|------|------|
| `/auth/register` | POST | 用户注册 | 否 |
| `/auth/login` | POST | 用户登录 | 否 |
| `/auth/logout` | POST | 用户登出 | 是 |
| `/auth/me` | GET | 获取当前用户信息 | 是 |
| `/auth/password` | PUT | 修改密码 | 是 |
| `/auth/forgetpwd` | PUT | 忘记密码 | 否 |

---

## 二、接口详情

### 2.1 用户注册

**接口路径：** `/auth/register`

**请求方法：** `POST`

**认证要求：** 否

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 中文说明 |
|--------|------|------|------|----------|
| username | string | Body | 是 | 用户名 |
| email | string | Body | 是 | 邮箱 |
| full_name | string | Body | 否 | 全名 |
| password | string | Body | 是 | 密码 |

**请求示例：**
```json
{
    "username": "zhangsan",
    "email": "zhangsan@example.com",
    "full_name": "张三",
    "password": "password123"
}
```

**成功响应：** `201 Created`

```json
{
    "code": 201,
    "message": "注册成功",
    "data": {
        "user": {
            "id": 1,
            "username": "zhangsan",
            "email": "zhangsan@example.com",
            "full_name": "张三",
            "is_active": true,
            "is_superuser": false,
            "created_at": "2024-01-01T00:00:00"
        },
        "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "token_type": "bearer"
    }
}
```

**错误响应：**

| 状态码 | 响应体 | 说明 |
|--------|--------|------|
| 400 | `{"code": 400, "message": "Username already registered", "data": null}` | 用户名已存在 |
| 400 | `{"code": 400, "message": "Email already registered", "data": null}` | 邮箱已被注册 |

---

### 2.2 用户登录

**接口路径：** `/auth/login`

**请求方法：** `POST`

**认证要求：** 否

**请求格式：** `application/x-www-form-urlencoded` (OAuth2 标准格式)

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 中文说明 |
|--------|------|------|------|----------|
| username | string | Body | 是 | 用户名 |
| password | string | Body | 是 | 密码 |

**请求示例：**
```
POST /auth/login
Content-Type: application/x-www-form-urlencoded

username=zhangsan&password=password123
```

**成功响应：** `200 OK`

```json
{
    "code": 200,
    "message": "登录成功",
    "data": {
        "username": "zhangsan",
        "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
        "token_type": "bearer"
    }
}
```

**错误响应：**

| 状态码 | 响应体 | 说明 |
|--------|--------|------|
| 401 | `{"code": 401, "message": "Incorrect username or password", "data": null}` | 用户名或密码错误 |

---

### 2.3 用户登出

**接口路径：** `/auth/logout`

**请求方法：** `POST`

**认证要求：** 是 (Bearer Token)

**请求参数：** 无（Token 通过 Authorization Header 传递）

**请求示例：**
```
POST /auth/logout
Authorization: Bearer <access_token>
```

**成功响应：** `200 OK`

```json
{
    "code": 200,
    "message": "登出成功",
    "data": "zhangsan"
}
```

**错误响应：**

| 状态码 | 响应体 | 说明 |
|--------|--------|------|
| 401 | `{"code": 401, "message": "Could not validate credentials", "data": null}` | Token 无效或已失效 |

---

### 2.4 获取当前用户信息

**接口路径：** `/auth/me`

**请求方法：** `GET`

**认证要求：** 是 (Bearer Token)

**请求参数：** 无（用户信息从 Token 中解析）

**请求示例：**
```
GET /auth/me
Authorization: Bearer <access_token>
```

**成功响应：** `200 OK`

```json
{
    "code": 200,
    "message": "获取成功",
    "data": {
        "id": 1,
        "username": "zhangsan",
        "email": "zhangsan@example.com",
        "full_name": "张三",
        "is_active": true,
        "is_superuser": false,
        "created_at": "2024-01-01T00:00:00"
    }
}
```

**错误响应：**

| 状态码 | 响应体 | 说明 |
|--------|--------|------|
| 401 | `{"code": 401, "message": "Could not validate credentials", "data": null}` | Token 无效或已失效 |

---

### 2.5 修改密码

**接口路径：** `/auth/password`

**请求方法：** `PUT`

**认证要求：** 是 (Bearer Token)

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 中文说明 |
|--------|------|------|------|----------|
| old_password | string | Body | 是 | 旧密码 |
| new_password | string | Body | 是 | 新密码 |

**请求示例：**
```json
{
    "old_password": "password123",
    "new_password": "newpassword456"
}
```

**成功响应：** `200 OK`

```json
{
    "code": 200,
    "message": "密码修改成功",
    "data": {
        "id": 1,
        "username": "zhangsan",
        "email": "zhangsan@example.com",
        "full_name": "张三",
        "is_active": true,
        "is_superuser": false,
        "created_at": "2024-01-01T00:00:00"
    }
}
```

**错误响应：**

| 状态码 | 响应体 | 说明 |
|--------|--------|------|
| 400 | `{"code": 400, "message": "Incorrect old password", "data": null}` | 旧密码错误 |
| 401 | `{"code": 401, "message": "Could not validate credentials", "data": null}` | Token 无效或已失效 |

---

### 2.6 忘记密码

**接口路径：** `/auth/forgetpwd`

**请求方法：** `PUT`

**认证要求：** 否

**功能说明：** 根据用户名查询用户信息，直接返回密码（不发送邮件）

**请求参数：**

| 参数名 | 类型 | 位置 | 必填 | 中文说明 |
|--------|------|------|------|----------|
| username | string | Query | 是 | 用户名 |

**请求示例：**
```
PUT /auth/forgetpwd?username=zhangsan
```

**成功响应：** `200 OK`

```json
{
    "code": 200,
    "message": "查询成功",
    "data": {
        "id": 1,
        "username": "zhangsan",
        "email": "zhangsan@example.com",
        "password": "password123",
        "is_superuser": false
    }
}
```

**错误响应：**

| 状态码 | 响应体 | 说明 |
|--------|--------|------|
| 400 | `{"code": 400, "message": "用户不存在", "data": null}` | 用户不存在 |

## 三、认证流程说明

### 3.1 请求认证流程

```
客户端请求
    │
    ▼
检查 Token 是否在黑名单 ────是───► 返回 401
    │否
    ▼
解析 JWT Token
    │
    ▼
验证 Token 有效性 ────无效───► 返回 401
    │有效
    ▼
获取用户信息
    │
    ▼
执行业务逻辑
```

### 3.2 Token 续期机制

当前实现中，Token 过期后用户需要重新登录获取新 Token，不支持自动续期。

### 3.3 登出机制

用户登出时，Token 会被加入 Redis 黑名单，已加入黑名单的 Token 无法再用于认证请求。

## 四、依赖服务

### 4.1 Redis

认证功能依赖 Redis 进行 Token 管理：

| 功能 | 说明 |
|------|------|
| Token 存储 | 存储有效 Token 及其过期时间 |
| Token 黑名单 | 存储已登出的 Token |
| 用户 Token 管理 | 支持同一用户多设备登录的 Token 管理 |

## 五、安全建议

| 问题 | 当前实现 | 建议改进 |
|------|---------|----------|
| 密码存储 | 明文存储 | 使用 bcrypt 等哈希算法 |
| Token 传输 | HTTP | 启用 HTTPS |
| Token 有效期 | 15 分钟 | 可根据场景调整 |
| 登录限制 | 无 | 添加登录失败次数限制 |
