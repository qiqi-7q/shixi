# 认证插件数据字典

## 一、User 用户表

| 字段名 | 数据库类型 | Pydantic类型 | 约束 | 中文说明 |
|--------|-----------|-------------|------|----------|
| id | Integer | int | 主键、自增、索引 | 用户ID |
| username | String(50) | str | 唯一、索引、非空 | 用户名 |
| email | String(100) | EmailStr | 索引、非空 | 邮箱 |
| hashed_password | String(255) | str | 非空 | 密码（当前明文存储） |
| full_name | String(100) | Optional[str] | 可空 | 全名 |
| is_active | Boolean | bool | 默认 True | 是否激活 |
| is_superuser | Boolean | bool | 默认 False | 是否超级管理员 |
| created_at | DateTime | datetime | 自动生成 | 创建时间 |
| updated_at | DateTime | datetime | 自动更新 | 更新时间 |

**表名：** `users`

**索引说明：**
- `id`：主键索引
- `username`：唯一索引，用于快速查询用户
- `email`：普通索引，用于邮件发送等场景

## 二、Schema 模型说明

### 2.1 UserBase 用户基础模型

| 字段名 | 类型 | 必填 | 中文说明 |

继承自 `UserBase`，新增密码字段：

| 字段名 | 类型 | 必填 | 中文说明 |
|--------|------|------|----------|
| username | str | 是 | 用户名 |
| email | EmailStr | 是 | 邮箱 |
| full_name | Optional[str] | 否 | 全名 |
| password | str | 是 | 密码（明文传输） |

### 2.3 UserLogin 用户登录模型

| 字段名 | 类型 | 必填 | 中文说明 |
|--------|------|------|----------|
| username | str | 是 | 用户名 |
| password | str | 是 | 密码 |

### 2.4 UserResponse 用户响应模型

继承自 `UserBase`，新增系统字段：

| 字段名 | 类型 | 中文说明 |
|--------|------|----------|
| id | int | 用户ID |
| username | str | 用户名 |
| email | EmailStr | 邮箱 |
| full_name | Optional[str] | 全名 |
| is_active | bool | 是否激活 |
| is_superuser | bool | 是否超级管理员 |
| created_at | datetime | 创建时间 |

### 2.5 Token 令牌模型

| 字段名 | 类型 | 中文说明 |
|--------|------|----------|
| access_token | str | 访问令牌（JWT） |
| token_type | str | 令牌类型（固定为 "bearer"） |

### 2.6 TokenData 令牌数据模型

JWT Token 解码后的数据结构：

| 字段名 | 类型 | 中文说明 |
|--------|------|----------|
| username | Optional[str] | 用户名（Subject） |

### 2.7 PasswordUpdate 密码更新模型

| 字段名 | 类型 | 必填 | 中文说明 |
|--------|------|------|----------|
| old_password | str | 是 | 旧密码 |
| new_password | str | 是 | 新密码 |

## 三、AuthService 服务方法

### 3.1 密码处理方法

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `verify_password` | `plain_password: str`, `stored_password: str` | `bool` | 验证密码（当前直接比较明文） |
| `get_password_hash` | `password: str` | `str` | 获取密码哈希（当前直接返回原密码） |

### 3.2 Token 方法

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `create_access_token` | `data: dict`, `expires_delta: Optional[timedelta]` | `str` | 创建 JWT 访问令牌 |

### 3.3 用户管理方法

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `authenticate_user` | `db: AsyncSession`, `username: str`, `password: str` | `User \| False` | 用户登录认证 |
| `create_user` | `db: AsyncSession`, `user: schemas.UserCreate` | `User` | 创建新用户 |
| `get_user` | `db: AsyncSession`, `user_id: int` | `User \| None` | 根据ID获取用户 |
| `get_user_by_username` | `db: AsyncSession`, `username: str` | `User \| None` | 根据用户名获取用户 |
| `update_password` | `db: AsyncSession`, `user_id: int`, `new_password: str` | `User` | 更新用户密码 |

## 四、Redis Token 管理

认证功能依赖 Redis 进行 Token 管理：

| 方法 | 参数 | 说明 |
|------|------|------|
| `set_token` | `user_id: int`, `token: str`, `expire_seconds: int` | 存储 Token 到 Redis |
| `is_token_blacklisted` | `token: str` | 检查 Token 是否在黑名单 |
| `blacklist_token` | `token: str` | 将 Token 加入黑名单 |
| `delete_token` | `user_id: int` | 删除用户的所有 Token |

## 五、错误信息说明

### 5.1 HTTP 状态码

| HTTP状态码 | 错误信息 | 说明 |
|------------|----------|------|
| 400 | `账号已存在` | 用户名已被注册 |
| 400 | `Incorrect old password` | 旧密码错误 |
| 400 | `用户不存在` | 忘记密码时用户不存在 |
| 401 | `Incorrect username or password` | 用户名或密码错误 |
| 401 | `Could not validate credentials` | Token 验证失败 |
| 404 | `User not found` | 用户不存在（内部） |
| 500 | `Failed to create user: {error}` | 用户创建失败 |

### 5.2 响应格式

所有接口统一响应格式：

```json
{
    "code": 状态码,
    "message": "提示信息",
    "data": 返回数据
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 业务状态码（非 HTTP 状态码） |
| message | str | 提示信息 |
| data | any | 返回数据（成功时）或 null（失败时） |

## 七、备注说明

### 7.1 密码存储说明

当前实现中，`hashed_password` 字段实际存储的是明文密码，这是一个安全风险。建议在生产环境中使用 bcrypt 或 Argon2 等哈希算法。

**当前实现方式：**
- `verify_password`：直接比较明文密码
- `get_password_hash`：直接返回原密码，不进行加密处理
- `create_user`：将明文密码直接存入数据库

### 7.2 邮箱验证说明

当前实现中，邮箱字段没有唯一约束，允许重复注册。代码中邮箱唯一性检查已被注释掉。

### 7.3 忘记密码说明

忘记密码功能会发送邮件到用户邮箱，但邮件内容直接包含明文密码，建议改进为发送一次性密码重置链接。

### 7.4 用户状态说明

| 字段 | 默认值 | 说明 |
|------|--------|------|
| is_active | True | 用户默认激活 |
| is_superuser | False | 用户默认非超级管理员 |
