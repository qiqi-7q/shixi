# 认证插件数据字典

## 一、User 用户表

| 字段名 | 数据库类型 | Pydantic类型 | 约束 | 中文说明 |
|--------|-----------|-------------|------|----------|
| id | Integer | int | 主键、自增 | 用户ID |
| username | String(50) | str | 唯一、索引、非空 | 用户名 |
| email | String(100) | EmailStr | 索引、非空 | 邮箱（允许重复） |
| hashed_password | String(255) | str | 非空 | 密码（明文存储） |
| full_name | String(100) | Optional[str] | 可空 | 全名 |
| is_active | Boolean | bool | 默认 True | 是否激活 |
| is_superuser | Boolean | bool | 默认 False | 是否超级管理员 |
| created_at | DateTime | datetime | 自动生成 | 创建时间 |
| updated_at | DateTime | datetime | 自动更新 | 更新时间 |

## 三、备注说明

### 3.1 密码存储说明

当前实现中，hashed_password 字段实际存储的是明文密码。

| 方法 | 说明 |
|------|------|
| verify_password | 直接比较明文密码 |
| get_password_hash | 直接返回原密码，不进行加密处理 |
| create_user | 将明文密码直接存入数据库 |

### 3.2 JWT Token 说明

| 配置项 | 说明 |
|--------|------|
| 算法 | HS256 |
| 密钥 | settings.SECRET_KEY |
| 过期时间 | 默认 15 分钟 |
| 存储 | Token 存储在 Redis 中 |

### 3.3 Redis Token 管理

| 方法 | 说明 |
|------|------|
| RedisService.set_token | 存储 Token 到 Redis |
| RedisService.is_token_blacklisted | 检查 Token 是否在黑名单 |
| RedisService.blacklist_token | 将 Token 加入黑名单 |
| RedisService.delete_token | 删除用户的所有 Token |

## 四、错误信息说明

| 错误信息 | HTTP状态码 | 说明 |
|----------|------------|------|
| Username already registered | 400 | 用户名已存在 |
| Email already registered | 400 | 邮箱已被注册 |
| Incorrect username or password | 401 | 用户名或密码错误 |
| Could not validate credentials | 401 | Token 验证失败 |
| Incorrect old password | 400 | 旧密码错误 |
| User not found | 404 | 用户不存在 |
