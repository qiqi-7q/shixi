# 司机监控插件接口文档

---

## 一、接口总览

所有接口前缀：`/api/driver_monitor`

| 接口路径                                             | 方法     | 说明               |
|--------------------------------------------------|--------|------------------|
| `/api/driver_monitor/createmonitor`              | POST   | 创建单条监控记录         |
| `/api/driver_monitor/fixsearch`                  | GET    | 获取监控记录列表（固定字段查询） |
| `/api/driver_monitor/getmonitor/{monitor_id}`    | GET    | 获取单条监控记录详情       |
| `/api/driver_monitor/updatemonitor/{monitor_id}` | PUT    | 更新监控记录           |
| `/api/driver_monitor/delmonitor/{monitor_id}`    | DELETE | 删除监控记录           |
| `/api/driver_monitor/stats/overview`             | GET    | 获取监控概览统计（卡片数据）   |
| `/api/driver_monitor/stats/daily_fatigue`        | GET    | 获取每日疲劳状态统计（折线图）  |
| `/api/driver_monitor/stats/daily_dms`            | GET    | 获取每日DMS触发次数（柱状图）  |
| `/api/driver_monitor/stats/driver_fatigue`       | GET    | 获取司机疲劳次数排行（柱状图）  |
| `/api/driver_monitor/stats/status_distribution`  | GET    | 获取状态分布统计（饼图）     |

---

## 二、统一响应格式

所有接口均采用以下统一响应格式：

```json
{
  "code": 200,
  "message": "success",
  "data": <业务数据或null>
}
```

| 字段      | 类型                | 说明                    |
|---------|-------------------|-----------------------|
| code    | int               | 状态码，200 表示成功，400 表示失败 |
| message | string            | 响应消息                  |
| data    | object/array/null | 业务数据，失败时为 null        |

### 2.2 分页接口响应格式（fixsearch）

```json
{
  "data": {
    "items": [...],
    "total": 50,
    "skip": 0,
    "limit": 100
  },
  "code": 200,
  "message": "success",
}
```

| 字段      | 类型                | 说明                    |
|---------|-------------------|-----------------------|
| data    | object            | 包含分页数据               |
| items   | array             | 数据列表                  |
| total   | int               | 总记录数                  |
| skip    | int               | 跳过的记录数               |
| limit   | int               | 返回的记录数               |
| code    | int               | 状态码，200 表示成功，400 表示失败 |
| message | string            | 响应消息                  |

---

### 3.1 DriverStatus 司机状态

## 四、接口详情

### 4.1 创建单条监控记录

**接口路径：** `/api/driver_monitor/createmonitor`

**请求方法：** `POST`

**请求参数（Body - JSON）：**

| 参数名                  | 类型              | 必填 | 默认值  | 约束  | 说明       |
|----------------------|-----------------|----|------|-----|----------|
| test_date            | date            | 是  | -    | -   | 测试日期     |
| test_start_time      | datetime        | 是  | -    | -   | 测试开始时间   |
| test_end_time        | datetime        | 是  | -    | -   | 测试结束时间   |
| vin_code             | string (max=17) | 是  | -    | 唯一  | 测试车辆VIN号 |
| driver_name          | string (max=50) | 是  | -    | -   | 司机姓名     |
| dms_trigger_count    | int             | 是  | -    | ≥ 0 | DMS触发次数  |
| distance             | Decimal         | 是  | -    | -   | 行驶里程     |
| power_start_duration | datetime        | 是  | -    | -   | 车辆上电开始时间 |
| power_end_duration   | datetime        | 是  | -    | -   | 车辆上电结束时间 |
| driver_status        | DriverStatus    | 是  | -    | 枚举  | 司机状态     |
| remark               | string          | 否  | None | -   | 备注       |

**driver_status 枚举值：** `正常`、`疲劳`、`轻微疲劳`、`严重疲劳`

**请求示例：**

```
POST /api/driver_monitor/createmonitor
```

```json
{
  "test_date": "2025-06-01",
  "test_start_time": "2025-06-01T09:00:00",
  "test_end_time": "2025-06-01T11:30:00",
  "vin_code": "LSVAU2180N2123456",
  "driver_name": "张三",
  "dms_trigger_count": 3,
  "distance": 125.50,
  "power_start_duration": "2025-06-01T08:55:00",
  "power_end_duration": "2025-06-01T11:35:00",
  "driver_status": "正常",
  "remark": "环路测试"
}
```

**成功响应：**

```json
{
  "code": 200,
  "message": "数据创建成功",
  "data": null
}
```

**错误响应：**

| code | message                                                    | 说明          |
|------|------------------------------------------------------------|-------------|
| 400  | 驾驶员监测信息不能为空                                            | 请求体为空       |
| 400  | 日期不能为空                                                  | 测试日期为空      |
| 400  | 测试时间不能为空                                                | 测试开始或结束时间为空 |
| 400  | 司机状态不能为空                                                | 司机状态为空      |
| 400  | 测试车辆VIN号不能为空                                            | VIN码为空      |
| 400  | 司机姓名不能为空                                                | 司机姓名为空      |
| 400  | DMS触发次数不能为空                                             | DMS触发次数为空   |
| 400  | 行驶里程不能为空                                                | 行驶里程为空      |
| 400  | 车辆上电时间段不能为空                                            | 上电时间为空      |
| 400  | 测试车辆VIN号已存在                                            | VIN码已存在     |

### 4.2 获取监控记录列表（固定字段查询）

**接口路径：** `/api/driver_monitor/fixsearch`

**请求方法：** `GET`

**请求参数：**

| 参数名             | 类型     | 位置    | 必填 | 默认值  | 查询方式           | 说明        |
|-----------------|--------|-------|----|------|----------------|-----------|
| skip            | int    | Query | 否  | 0    | -              | 跳过记录数（≥0） |
| limit           | int    | Query | 否  | 100  | -              | 返回记录数     |
| driver_name     | string | Query | 否  | None | 模糊匹配（contains） | 司机姓名      |
| vin_code        | string | Query | 否  | None | 精确匹配（==）       | VIN码      |
| test_start_date | date   | Query | 否  | None | 大于等于（>=）       | 测试起始日期筛选  |
| test_end_date   | date   | Query | 否  | None | 小于等于（<=）       | 测试截止日期筛选  |

> **说明：** `driver_name` 为模糊查询，`vin_code` 为精确匹配，`test_start_date` 和 `test_end_date` 构成日期范围查询（对
`test_date` 字段进行 `>=` 和 `<=` 过滤）。

```
GET /api/driver_monitor/fixsearch?skip=0&limit=10&driver_name=张三&test_start_date=2025-06-01&test_end_date=2025-06-30

## 七、已知问题与注意事项

### 7.3 业务关联说明

`vin_code` 字段与 `vehicles` 表的 `vin_code` 在业务上存在逻辑关联（代表同一辆测试车辆），但未建立数据库外键约束。在数据录入时需确保
VIN 码的一致性。

**请求参数：**

| 参数名         | 类型     | 位置    | 必填 | 默认值  | 说明         |
|--------------|--------|-------|----|------|------------|

GET /api/driver_monitor/stats/overview?driver_name=大飒飒&driver_status=FATIGUE&start_date=2026-06-18&end_date=2026-07-16
```

| 字段          | 类型    | 说明       |
|-------------|-------|----------|

| status_counts | array | 各状态数量统计  |
