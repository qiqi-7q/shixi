## 一、枚举类型定义

### 1.1 DriverStatus 司机状态

| 枚举值  | 英文标识          | 中文说明   |
|------|---------------|--------|
| 正常   | NORMAL        | 司机状态正常 |
| 疲劳   | FATIGUE       | 司机疲劳   |
| 轻微疲劳 | MILDFAIR      | 司机轻微疲劳 |
| 严重疲劳 | SEVEREFATIGUE | 司机严重疲劳 |

## 二、driver_monitors 司机监控记录表

### 2.1 表结构

| 字段名                  | 数据库类型              | Pydantic类型             | 长度/精度  | 必填 | 默认值   | 约束       | 中文说明     |
|----------------------|--------------------|------------------------|--------|----|-------|----------|----------|
| id                   | Integer            | int                    | -      | 是  | 自增    | 主键、索引    | 主键ID     |
| test_date            | Date               | date                   | -      | 是  | -     | 非空       | 测试日期     |
| test_start_time      | DateTime           | datetime               | -      | 是  | -     | 非空       | 测试开始时间   |
| test_end_time        | DateTime           | datetime               | -      | 是  | -     | 非空       | 测试结束时间   |
| driver_status        | Enum(DriverStatus) | Optional[DriverStatus] | -      | 是  | 正常    | 非空       | 司机状态     |
| vin_code             | String             | str                    | 17     | 是  | -     | 唯一、索引、非空 | 测试车辆VIN号 |
| driver_name          | String             | str                    | 50     | 是  | -     | 非空       | 司机姓名     |
| dms_trigger_count    | Integer            | int (ge=0)             | -      | 是  | -     | 非空       | DMS触发次数  |
| distance             | DECIMAL            | Decimal                | (10,2) | 是  | -     | 非空       | 行驶里程     |
| power_start_duration | DateTime           | datetime               | -      | 是  | -     | 非空       | 车辆上电开始时间 |
| power_end_duration   | DateTime           | datetime               | -      | 是  | -     | 非空       | 车辆上电结束时间 |
| remark               | Text               | Optional[str]          | -      | 否  | -     | 可空       | 备注       |
| create_time          | DateTime           | datetime               | -      | 否  | now() | 自动生成     | 创建时间     |
| update_time          | DateTime           | datetime               | -      | 否  | now() | 自动更新     | 更新时间     |

### 2.2 索引

| 索引类型 | 字段       | 说明     |
|------|----------|--------|
| 主键索引 | id       | 自增主键   |
| 唯一索引 | vin_code | VIN码唯一 |

### 2.3 字段值域说明

| 字段                | 值域/约束         | 说明                                               |
|-------------------|---------------|--------------------------------------------------|
| test_date         | Date          | 格式 `YYYY-MM-DD`，如 `2025-06-01`                   |
| test_start_time   | DateTime      | 格式 `YYYY-MM-DDTHH:MM:SS`，如 `2025-06-01T09:00:00` |
| test_end_time     | DateTime      | 必须晚于 `test_start_time`                           |
| dms_trigger_count | Integer，≥ 0   | DMS 系统触发报警的次数，不能为负数                              |
| distance          | DECIMAL(10,2) | 精度为 10 位整数 + 2 位小数，如 `125.50`                    |
| driver_status     | Enum          | 取值为 `正常`、`疲劳`、`轻微疲劳`、`严重疲劳`                      |

## 三、Schema 模型说明

### 3.1 DriverMonitorBase 司机监控基础模型

| 字段名                  | 类型                     | 必填 | 默认值  | 约束       | 说明       |
|----------------------|------------------------|----|------|----------|----------|
| test_date            | date                   | 是  | -    | -        | 测试日期     |
| test_start_time      | datetime               | 是  | -    | -        | 测试开始时间   |
| test_end_time        | datetime               | 是  | -    | -        | 测试结束时间   |
| vin_code             | str (max=17)           | 是  | -    | -        | 测试车辆VIN号 |
| driver_name          | str (max=50)           | 是  | -    | -        | 司机姓名     |
| dms_trigger_count    | int                    | 是  | -    | ge=0（≥0） | DMS触发次数  |
| distance             | Decimal                | 是  | -    | -        | 行驶里程     |
| power_start_duration | datetime               | 是  | -    | -        | 车辆上电开始时间 |
| power_end_duration   | datetime               | 是  | -    | -        | 车辆上电结束时间 |
| driver_status        | Optional[DriverStatus] | 是  | -    | -        | 司机状态     |
| remark               | Optional[str]          | 否  | None | -        | 备注       |

> **注意：** `driver_status` 在 Pydantic 模型中标记为 `Optional[DriverStatus]`，但 `Field(...)` 表示必填，实际上为**必填的可选枚举
**，需传入 `DriverStatus` 枚举值之一。

### 3.2 DriverMonitorCreate 创建司机监控记录模型

继承自 DriverMonitorBase，字段与 DriverMonitorBase 完全一致。

### 3.3 DriverMonitorUpdate 更新司机监控记录模型

所有字段均为可选，仅传入需要更新的字段。

| 字段名                  | 类型                     | 必填 | 默认值  | 约束       | 说明       |
|----------------------|------------------------|----|------|----------|----------|
| test_date            | Optional[date]         | 否  | None | -        | 测试日期     |
| test_start_time      | Optional[datetime]     | 否  | None | -        | 测试开始时间   |
| test_end_time        | Optional[datetime]     | 否  | None | -        | 测试结束时间   |
| vin_code             | Optional[str] (max=17) | 否  | None | -        | 测试车辆VIN号 |
| driver_name          | Optional[str] (max=50) | 否  | None | -        | 司机姓名     |
| dms_trigger_count    | Optional[int]          | 否  | None | ge=0（≥0） | DMS触发次数  |
| distance             | Optional[Decimal]      | 否  | None | -        | 行驶里程     |
| power_start_duration | Optional[datetime]     | 否  | None | -        | 车辆上电开始时间 |
| power_end_duration   | Optional[datetime]     | 否  | None | -        | 车辆上电结束时间 |
| remark               | Optional[str]          | 否  | None | -        | 备注       |
| driver_status        | Optional[DriverStatus] | 否  | None | -        | 司机状态     |

### 3.4 DriverMonitorResponse 司机监控记录响应模型

继承自 DriverMonitorBase，额外包含数据库自动生成的字段。

| 字段名                         | 类型       | 说明   |
|-----------------------------|----------|------|
| （继承 DriverMonitorBase 所有字段） | -        | -    |
| id                          | int      | 主键ID |
| create_time                 | datetime | 创建时间 |
| update_time                 | datetime | 更新时间 |

> 配置 `model_config = ConfigDict(from_attributes=True)`，支持从 ORM 模型直接转换。

### 3.5 DriverMonitorBatchImport 批量导入模型

当前模型定义为 `pass`（未实现），预留用于批量导入功能扩展。

## 四、业务校验规则说明

### 4.1 创建司机监控记录校验规则

| 校验项                  | 校验规则 | 错误信息                                                  | 说明                        |
|----------------------|------|-------------------------------------------------------|---------------------------|
| monitor 数据           | 非空   | Monitor is missing                                    | 请求体不能为空                   |
| test_date            | 非空   | Test date is missing                                  | 测试日期必填                    |
| test_start_time      | 非空   | Test start time or test end time is missing           | 测试开始时间必填                  |
| test_end_time        | 非空   | Test start time or test end time is missing           | 测试结束时间必填                  |
| driver_status        | 非空   | Driver status is missing                              | 司机状态必填                    |
| vin_code             | 非空   | VIN code is missing                                   | VIN码必填                    |
| driver_name          | 非空   | Driver name is missing                                | 司机姓名必填                    |
| test_distance        | 非空   | Test distance is missing                              | ⚠️ **此字段不存在于模型中，校验将触发错误** |
| distance             | 非空   | Distance is missing                                   | 行驶里程必填                    |
| power_start_duration | 非空   | Power start duration or power end duration is missing | 上电开始时间必填                  |
| power_end_duration   | 非空   | Power start duration or power end duration is missing | 上电结束时间必填                  |
| vin_code 唯一性         | 不重复  | vin_code already exists                               | VIN码不能与已有记录重复             |

### 4.2 更新司机监控记录校验规则

| 校验项   | 校验规则   | 错误信息              | 说明                         |
|-------|--------|-------------------|----------------------------|
| 记录存在性 | 记录必须存在 | monitor not found | 更新的记录必须存在                  |
| 同创建校验 | 同上     | 同上                | 更新时复用 `monitor_check` 校验逻辑 |

## 五、表关联关系

当前模块**仅包含单表** `driver_monitors`，无外键关联。`vin_code` 字段与 `vehicles` 表的 `vin_code`
在业务上存在逻辑关联，但未建立数据库层面的外键约束。
