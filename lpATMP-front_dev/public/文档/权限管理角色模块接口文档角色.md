🎭 角色管理
14. 获取角色列表

plainText
GET /api/auth/roles?skip=0&limit=100&search=user
权限: role:read

Query 参数:

参数	类型	默认值	说明
skip	int	0	跳过条数
limit	int	100	返回条数（1-500）
search	string	NULL	按不同角色搜索/不传默认获取全部角色信息
响应:


json
{
    "code": 200,
    "message": "获取成功",
    "data": {
        "items": [ /* RoleResponse[] */ ],
        "total": 7,
        "skip": 0,
        "limit": 100
    }
}
15. 获取角色详情（按 ID）

plainText
GET /api/auth/roles/{role_id}
权限: role:read

路径参数: role_id — 角色 ID（int）

16. 获取角色详情（按 UUID）

plainText
GET /api/auth/roles/uuid/{role_uuid}
权限: role:read

路径参数: role_uuid — 角色 UUID（如 70165e76-7f93-40c3-847a-25054f1f013e）

17. 创建角色

plainText
POST /api/auth/roles
权限: role:add  

请求体 (JSON):


json
{
    "code": "tester（必填，同平台唯一）",
    "name": "测试员（必填）",
    "description": "测试人员（可选）",
    "permission_ids": [1, 2, 3],
    "platform_uuid": "dec2fe4f-...（必填，UUID）",
    "level": 1
}
角色等级参考:

level	角色
100	superuser
50	admin
1	user / viewer / visitor
响应:


json
{
    "code": 201,
    "message": "创建成功",
    "data": { /* RoleResponse */ }
}
错误码: 400 该平台下角色 code 已存在

18. 更新角色

plainText
PUT /api/auth/roles/{role_id}
权限: role:update

路径参数: role_id — 角色 ID（int）

请求体 (JSON，全部可选):


json
{
    "code": "tester_v2",
    "name": "测试员V2",
    "description": "更新后的描述",
    "permission_ids": [1, 2, 3, 4],
    "platform_uuid": "dec2fe4f-...（UUID）",
    "level": 10
}
19. 删除角色

plainText
DELETE /api/auth/roles/{role_id}
权限: role:delete

路径参数: role_id — 角色 ID（int）

响应:


json
{
    "code": 200,
    "message": "删除成功",
    "data": "被删除的角色名"
}
