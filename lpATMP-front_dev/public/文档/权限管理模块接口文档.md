权限管理模块 API 文档
Base URL: http://127.0.0.1:8000/api/auth

🔐 认证
1. 用户注册

plainText
POST /api/auth/register?platform=platform_a
权限: 无需认证

Query 参数:

参数	类型	必填	说明
platform	string	✅	平台编码，如 platform_a、platform_b
请求体 (JSON):


json
{
    "username": "string（必填）",
    "password": "string（必填）"
}
响应:


json
{
    "code": 201,
    "message": "注册成功",
    "data": {
        "user": { /* UserResponse */ },
        "access_token": "eyJ...",
        "token_type": "bearer"
    }
}
注册后自动分配当前平台 code=user 的角色，账号默认激活


3. 游客登录

plainText
POST /api/auth/visitor_login
权限: 无需认证

请求体 (form-data):

参数	类型	必填	说明
platform	string	✅	平台编码
响应:


json
{
    "code": 200,
    "message": "游客登录成功",
    "data": {
        "userid": 10,
        "username": "visitor",
        "full_name": "游客",
        "platform": "platform_a",
        "role_name": "visitor",
        "permissions": ["user:read", "vehicle:read", "..."],
        "access_token": "eyJ...",
        "token_type": "bearer"
    }
}
自动匹配当前平台 level 最低角色的用户（visitor/viewer），不依赖命名



6. 修改密码

plainText
PUT /api/auth/password
权限: 需登录

请求体 (JSON):


json
{
    "old_password": "string（必填）",
    "new_password": "string（必填）"
}
响应:


json
{
    "code": 200,
    "message": "密码修改成功",
    "data": { /* UserResponse */ }
}
错误码: 400 旧密码错误

用户不存在 / 400 未绑定邮箱 / 500 邮件发送失败

👤 用户管理
8. 获取用户列表（分页）

plainText
GET /api/auth/users?skip=0&limit=10&role_name=admin&platform=platform_a
权限: user:read

Query 参数:

参数	类型	默认值	说明
skip	int	0	跳过条数
limit	int	10	返回条数（1-500）
role_name	string	—	按角色 code 过滤
platform	string	—	按平台 code 过滤
响应:


json
{
    "code": 200,
    "message": "获取成功",
    "data": {
        "items": [ /* UserResponse[] */ ],
        "total": 50,
        "skip": 0,
        "limit": 10
    }
}
9. 获取用户列表（搜索/排序）

plainText
GET /api/auth/users/fixsearch?skip=0&limit=10&username=admin&role_name=admin&platform=platform_a&sort_by=username&sort_order=asc
权限: user:read

Query 参数:

参数	类型	默认值	说明
skip	int	0	跳过条数
limit	int	10	返回条数（1-500）
username	string	—	用户名模糊搜索
role_name	string	—	按角色 code 过滤
platform	string	—	按平台 code 过滤
sort_by	string	—	排序字段（见白名单）
sort_order	string	asc	asc / desc
排序字段白名单: id, uuid, username, email, full_name, is_active, is_oa_account, role_uuid, platform_uuid, create_at, update_at, create_by, update_by

10. 管理员创建用户

plainText
POST /api/auth/users
权限: user:add

请求体 (JSON):


json
{
    "username": "string（必填）",
    "password": "string（可选）",
    "email": "string（可选）",
    "full_name": "string（可选）",
    "is_oa_account": false,
    "platform_uuid": "dec2fe4f-...（必填，UUID）",
    "role_uuid": "70165e76-...（可选，UUID）",
    "role": "admin（可选，按角色 code 指定，优先级低于 role_uuid）"
}
响应:


json
{
    "code": 201,
    "message": "创建成功",
    "data": { /* UserResponse */ }
}
错误码: 400 账号已存在 / 403 无权操作同级或更高级角色用户

12. 更新用户

plainText
PUT /api/auth/users/{user_id}
权限: user:update

路径参数: user_id — 用户 ID（int）

请求体 (JSON，全部可选):


json
{
    "password": "newpassword",
    "email": "new@example.com",
    "full_name": "新名称",
    "is_oa_account": false,
    "role_uuid": "70165e76-...（UUID）",
    "is_active": true

响应:


json
{
    "code": 200,
    "message": "更新成功",
    "data": { /* UserResponse */ }
}
错误码: 404 用户不存在 / 403 无权修改

13. 删除用户

plainText
DELETE /api/auth/users/{user_id}
权限: user:delete

路径参数: user_id — 用户 ID（int）

响应:


json
{
    "code": 200,
    "message": "删除成功",
    "data": "被删除的用户名"
}
错误码: 400 不能删除自己 / 404 用户不存在

17. 创建角色

plainText
POST /api/auth/roles
权限: role:add

请求体 (JSON):


json
{
    "code": "tester（必填，同平台唯一）",
    "name": "测试员（必填）",
    "description": "测试人员（可选）",
    "permission_ids": [1, 2, 3],
    "platform_uuid": "dec2fe4f-...（必填，UUID）",
    "level": 1
}
角色等级参考:

level	角色
100	superuser
50	admin
1	user / viewer / visitor
响应:


json
{
    "code": 201,
    "message": "创建成功",
    "data": { /* RoleResponse */ }
}
错误码: 400 该平台下角色 code 已存在

POST /visitor_login — 游客登录
